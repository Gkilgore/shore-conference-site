# Automatic Instagram gallery implementation plan

Work in a feature branch from current `origin/main`; retain `docs/automatic-instagram-gallery.md`. Never alter the live Supabase project. Do not publish until Greg directs it.

1. **Meta integration spike.** Confirm the current Instagram Login authorization URL, redirect requirements, token lifecycle, media fields, account eligibility, app-review requirements, and policy for display and retention using Meta's primary documentation. Establish a conference-owned test app and a consenting professional-account tester. Record findings without putting app secrets or tokens in files. Test the end-to-end flow before promising the final AD instructions.
2. **Database and security.** Design account-to-school/team associations, private token storage, expiring one-use OAuth state, refresh state, and minimal cached post metadata after verifying Meta's retention rules. Prepare migrations and rolled-back SQL tests. Verify current staff privileges at both initiation and callback; prohibit cross-school connections, replay and token exposure. RLS is required on all new tables. Disconnect must immediately suppress public posts and remove credentials and cached content.
3. **Server integration.** Add small Supabase Edge Functions for authorized connection start, callback, disconnect and refresh, using established repository function conventions. Keep secrets server-side. Synchronize safely under concurrent refresh, restrict outbound requests to Meta, handle expired grants, deleted posts and failed refreshes. Verify no public response or logs disclose tokens. Deploy only to the test project after tests pass.
4. **AD workflow.** Extend the Social media tab to manage several labeled team accounts and display connection/refresh status. Provide the guide in `docs/automatic-instagram-gallery.md` as contextual help, updated to match the verified real Meta prompts. Include reconnect and disconnect. Continue honoring AD, conference and site-admin access.
5. **Gallery.** Replace the single-school picker and profile-grid embed with individual post cards ordered newest first, filtered by school on school pages. Identify team, school and platform, link to each original post, use safe text rendering and accessible media fallbacks. Preserve existing Facebook and X links. Exercise ordering, filtering, missing media, videos, stale/deleted posts and disconnected accounts with fictional fixtures.
6. **Integration verification.** Run `node --test tests/*.test.mjs`, database permission tests, and real test-account flows for AD and conference admin. Confirm a second school's records cannot be changed via API, public data has no credentials, refresh and removal propagate, and an AD can follow the guide. Record limitations and Meta review status. Name a removal-request contact before rollout.
