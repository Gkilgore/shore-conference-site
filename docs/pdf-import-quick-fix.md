# Quick Fix: "Scanned PDF Image" Error

**You're getting this error?** Your PDF is a scan or screenshot and needs OCR conversion first.

## 30-Second Fix

1. Go to [ILovePDF.com OCR](https://www.ilovepdf.com/ocr)
2. Upload your PDF → Click "Convert to PDF"
3. Download the new PDF
4. Upload it to Shore Conference
5. Done! ✓

## Still Doesn't Work?

Create a CSV instead:
1. In Shore Conference, download the Import CSV template
2. Copy your game info into the spreadsheet
3. Save as CSV
4. Upload to Shore Conference

**This always works** because it doesn't rely on OCR extraction.

## Why This Happens

- **Scanned PDF:** Image file, needs OCR to extract text ❌
- **Searchable PDF:** Text file, can extract directly ✓
